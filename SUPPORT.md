# Getting help with NOOP for Mac

- **Bugs:** open a [GitHub issue](../../issues/new/choose) using the bug template. Include the
  version or commit you built, your macOS version, the strap model and, where possible, a **strap
  log** (Live screen → Strap log card → Copy / Save…). NOOP runs entirely on your Mac, so the log is
  usually the only way to tell a real fault from a setup detail.
- **Ideas and questions:** open a GitHub issue using the feature template.
- **Security problems:** report privately as described in [`SECURITY.md`](SECURITY.md).
- **Build problems:** see [`docs/BUILD.md`](docs/BUILD.md) first.

Please leave out anything personal (strap serial, account email, raw health exports).

This is an unofficial fork of [NOOP](https://github.com/NoopApp/noop); please do not send reports
about this fork upstream. NOOP is **not affiliated with WHOOP, Inc.** and is **not a medical device**.
